================================================================================
                           WHAT WAS BUILT
================================================================================

CargoOpt 3D Packer is a fully functional 3D puzzle/management game where you
act as a "Load Master" to efficiently fit passenger luggage into an aircraft
cargo hold.

KEY FEATURES:
✅ Flight Selection Screen - Choose from available flights
✅ 3D Cargo Container - Interactive Three.js visualization
✅ Red Zone - Passenger luggage area (1.05 m³)
✅ Green Zone - Commercial cargo area (131.10 m³)
✅ Luggage Queue - Sidebar with all passenger bags
✅ Click-to-Place - Simple interaction model
✅ Collision Detection - Prevents overlapping bags
✅ Boundary Checking - Keeps bags in Red Zone
✅ Progress Tracking - Real-time loading progress
✅ Win Condition - All bags loaded = victory
✅ Professional UI - Dark theme with slate colors
✅ Responsive Design - Works on all screen sizes

================================================================================
                        HOW TO PLAY
================================================================================

STEP 1: SELECT A FLIGHT
- Open https://cargoopt-3-d-packer.lindy.site
- View flight AB201 details
- Click "Start Loading" button

STEP 2: LOAD LUGGAGE
- See 3D cargo container on the left
- See luggage queue on the right sidebar
- Click on any bag to place it in the cargo hold
- Game automatically finds valid position without collisions

STEP 3: COMPLETE THE MISSION
- Continue clicking bags until all 10 are loaded
- Watch progress bar fill up
- When complete, see "🎉 All Bags Loaded!" message
- Click "Back" to return to flight selector

CONTROLS:
- Left Click: Select and place luggage
- Scroll: Zoom in/out on 3D scene
- Right Click + Drag: Rotate 3D view
- ✕ Button: Remove placed bag to reposition
